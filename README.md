# FilmMood 🎬

FilmMood is a web application that recommends movies based on the user's mood using the TMDB API.

## Features

- Movie recommendations based on mood
- User registration and login system
- JWT authentication
- Favorite movies system
- Dynamic movie fetching from TMDB API
- Responsive user interface
- Modern UI design

## Technologies

### Frontend
- HTML5
- CSS3
- JavaScript (ES6)

### Backend
- Node.js
- Express.js
- SQLite

### Other
- REST API
- JWT Authentication
- TMDB API
